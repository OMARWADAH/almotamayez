# المتميز الراقي للدعاية والإعلان — الموقع

كتالوج عربي (RTL) لمنتجات الطباعة والدعاية مع طلب مباشر عبر واتساب (+966599293545) ولوحة تحكم محمية.

## التشغيل
```
npm install
node server.js        # http://localhost:3000
```
- لوحة التحكم: `/admin` — بيانات الدخول الأولى تُنشأ تلقائيًا في `data/admin-credentials.txt`. غيّر كلمة المرور من تبويب «الحساب» ثم احذف الملف.
- يمكن تحديد بيانات الدخول مسبقًا بمتغيرات البيئة `ADMIN_USER` و`ADMIN_PASSWORD` قبل أول تشغيل.
- متغيرات اختيارية: `PORT`، `DATA_DIR` (قاعدة البيانات)، `UPLOADS_DIR` (الصور المرفوعة).

## البنية
- `server.js` — الخادم، الصفحات، واجهة لوحة التحكم (تحقق من الجلسة والمصدر في كل إضافة/تعديل/حذف).
- `src/db.js` — قاعدة بيانات SQLite دائمة (`data/site.db`) والبذر الأولي.
- `src/catalog-data.js` — الأقسام والمنتجات والتشطيبات الأولية (تُدرج كمسودات).
- `src/sample-images.js` — صور توضيحية مستقلة لكل منتج موسومة «نموذج توضيحي».
- `src/search.js` — البحث العربي (توحيد الحروف + المرادفات المتداولة).
- `src/views.js` — قوالب الصفحات. `public/` — التنسيقات والسكربتات. `admin/` و`public/admin-assets/` — لوحة التحكم.
- `uploads/` — الصور المرفوعة (نسخة 1200px، نسخة جوال 480px، صورة مشاركة 1200×630).

## النشر المجاني: Render + Turso + Cloudinary
على الاستضافة تُحفظ البيانات في Turso، وتُحفظ الصور في Cloudinary، لأن قرص Render المجاني يُمسح عند كل إعادة تشغيل.

1. **Turso (قاعدة البيانات):** سجّل في turso.tech وأنشئ قاعدة بيانات باسم `almotamayez`. انسخ منها:
   - **Database URL**، ويبدأ بـ `libsql://`
   - **Auth Token**، من زر Generate Token
2. **Cloudinary (الصور):** سجّل في cloudinary.com، ثم من صفحة Dashboard انسخ **API Environment variable**. يبدأ بـ `cloudinary://`.
3. **GitHub:** ارفع المشروع إلى مستودع جديد.
4. **Render:**
   1. سجّل في render.com بحساب GitHub.
   2. اختر **New → Blueprint** ثم اختر المستودع. سيقرأ Render ملف `render.yaml` تلقائيًا.
   3. أدخل قيم المتغيرات:
      - `TURSO_DATABASE_URL`
      - `TURSO_AUTH_TOKEN`
      - `CLOUDINARY_URL`
      - `ADMIN_PASSWORD`: كلمة مرور قوية للوحة التحكم، 10 أحرف أو أكثر.
5. انتظر انتهاء البناء، وسيصبح الموقع متاحًا على رابط مثل `https://almotamayez.onrender.com`.
   - ادخل `/admin` باسم المستخدم `admin` وكلمة المرور التي اخترتها.
   - راجع المنتجات وانشرها.
   - اكتب رابط الموقع في حقل «رابط الموقع الأساسي».

ملاحظة: الخطة المجانية في Render تُنيم الموقع بعد 15 دقيقة بدون زيارات، وأول زيارة بعدها تأخذ نحو 50 ثانية.
